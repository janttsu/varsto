# Manual test checklists

Windows, macOS, Android and iOS are tested by hand on real devices. Use one checklist per platform, record results with [../report-template.md](../report-template.md), and mark hardware-dependent items clearly.

Common checks for every platform: install and first launch, alpha warning shown and acknowledged, create a vault, add a storage, sync a folder, restore a file from version history and trash, language switch, light and dark theme, uninstall leaves no unexpected data behind.
