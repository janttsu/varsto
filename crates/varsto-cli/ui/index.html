    Overview

    Alpha software: not for production data. Keep your own backups.

    Welcome to Varsto

    Create a new vault, join one of your existing vaults, or accept a folder that someone shared with you. Everything is encrypted on this device before it reaches any storage.

    Create a new vault here if this is your first device. If you already use Varsto, join your vault with the vault key shown on the other device.

    Create a new vault

    You will be shown the vault key once. Write it down and keep it offline; it is the only way to add other devices or recover the data.

    Join an existing vault

    The secret is kept in this device's encrypted secret store, never in a plain file.

    Accept a shared folder

    Step 1: send the owner a request code from this device. Step 2: paste the sealed token they send back.

    
        
        
        
    
        
    You get the folder key only: this device can read and write that folder, nothing else of the other vault. A sealed token (vst1…) can be opened only here; a plain token carries the key itself.

      Shared folders
      
        
        
        
        Nothing shared yet
        Open a folder under Files and press Share to create a token for another Varsto user. Ask them for their request code first to seal the token to their device.
        
        
        
      
        
      
        
        
        Untrusted replica
        
        
        A replica holds and verifies your encrypted copies without any key to open them: a friend's NAS or a server you rent.
        
        
        
        
        
      
        
    
        

    
    
        
      
        
        
        Storages
        
        
        Encrypted objects are written to every storage. Varsto never sends a key anywhere; a storage sees only sealed blocks.
        
        
          
        
          No storage yet
          Add a directory, an S3 bucket, an rclone remote or a pool of removable disks below.
          
      
          
      
          
      
          
        
          Add a disk to a pool
          
        
        
        
        
          
        
          The disk gets a small marker file and a varsto directory, then is filled with what the pool does not hold yet. Varsto never formats a disk.
          
      
          
      
          
        
          Add a storage
          
        
        
        
          
          
          
        
          
        
          
          
          
          
          
          
          
          
          
          
          The secret is stored encrypted in this device's secrets.enc and never in config.json. Archive classes are treated as cold.
          
        
          
        
          
          
          
          Uses your rclone and its configuration; Varsto never sees the remote's credentials.
          
        
          
        
          
          
          
          
          Disks are added one by one below once the pool exists. Each disk takes encrypted blocks until its reserve is reached; a disk that is away is remembered, and files on it say so.
          
        
          
        
        
          
      
          
    
          

    
    
          
      
          
        
          Durability policies
          
        
          A policy states how many copies a folder must have, where, and how recently another device must have verified them. Varsto checks it against the ledger on every sync and tells you before a rule is broken.
          
        
            
        
            No folders yet
            Policies are set per folder.
            
      
            
    
            

    
    
            
      
            
        
            Devices
            
        
            
      
            
      
            
        Peer-to-peer transfer
        
            Your devices exchange encrypted blocks directly: on the LAN automatically, across the internet through NAT with hole punching, and when that fails through one of your own reachable devices acting as a relay. Blocks are verified by name; a peer needs the vault key and a known certificate to get anything.

            Appearance

            Plain files on this phone
            
          
            A folder in "plain files" mode is synced as ordinary files under Internal storage/Varsto, where My Files and the gallery can see them. Android asks for all files access for that; folders kept encrypted on the phone need nothing.
            
          
            
          
            
        
            
        
            
          
            Service
            
          
            The background service watches your folders and serves this interface on this computer only. Quitting stops syncing until Varsto is started again.

            Start over on this device alpha
            
        
            Removes this device's vault configuration: its keys, the ledger copy, sync state and any folder grants. Your files stay where they are, and nothing on the storages or on other devices is touched. Afterwards the setup screen appears and you can create a new vault or join one again.
