Overview

Alpha software: not for production data. Keep your own backups.

Set up this device

Create a new vault, join one of your existing vaults, or accept a folder that someone shared with you. Everything is encrypted on this device before it reaches any storage.

Create a new vault

You will be shown the vault key once. Write it down and keep it offline; it is the only way to add other devices or recover the data.

Join an existing vault

Accept a shared folder

Step 1: send the owner a request code from this device. Step 2: paste the sealed token they send back.


        
        
        

        
You get the folder key only: this device can read and write that folder, nothing else of the other vault. A sealed token (vst1…) can be opened only here; a plain token carries the key itself.

        Devices
        
        
        
      
        
      
        
        Peer-to-peer transfer
        
        Your devices exchange encrypted blocks directly: on the LAN automatically, across the internet when one of them listens on a reachable address. Blocks are verified by name; a peer needs the vault key to get anything.
        
        
        
        
        
          
          
          
          
        
        
        
      
        
    
        

    
    
        
      
        
      
        
        
        
          
        Share a folder
        
          
        Press Share on a folder in the Overview to create a share token. Ask the recipient for their request code first to seal the token to their device; a plain token carries the folder key itself and must travel over a secure channel.
        
          
        
        
        
        
        
          
        Untrusted replica
        
          
        A replica holds and verifies your encrypted copies without any key to open them: a friend's NAS or a server you rent.
