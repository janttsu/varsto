Lataukset

Katso kuvakaappauksista, miltä alfa näyttää.

Jokaiselle alustalle yksi paketti, jossa ovat taustapalvelu, käyttöliittymä ja sama komentorivi; Linuxissa ja macOS:ssä palvelu käynnistyy kirjautuessa (systemd-käyttäjäyksikkönä tai launch agentina), Windowsissa sitä ajaa ilmoitusalueen sovellus. Linuxissa ja Windowsissa käyttöliittymä avautuu selaimeesi; macOS:ssä natiivisovelluksella on oma ikkunansa. Alfa: käytä vain testidatalla ja pidä huolta omista varmuuskopioistasi.

Verify your download

SHA256SUMS is signed with the Varsto release key (SHA256SUMS.sig, minisign format). The key is kept offline, built into every varsto binary and published in the repository and here; key ID 2861CE1D220B07F3:

RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF

With Varsto already installed, put SHA256SUMS and SHA256SUMS.sig next to the download (or leave them out to fetch them) and run

varsto verify-release varsto-0.0.1-alpha.12-x86_64-unknown-linux-musl.tar.gz --github

--github also compares the checksum with the list attached to the GitHub release, a second channel. Without Varsto, use minisign and then check the hash:

minisign -Vm SHA256SUMS -x SHA256SUMS.sig -P RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF
sha256sum -c --ignore-missing SHA256SUMS

varsto update does all of this by itself and refuses an update whose signature or checksum does not match.

Kääntäminen lähdekoodista

Lähdekoodi on osoitteessa github.com/janttsu/varsto; jokainen julkaisu on siellä tagi, jonka GitHub-julkaisuun on liitetty samat tiedostot, ja alla oleva lähdekoodiarkisto vastaa sitä. Vakaalla Rust-työkaluketjulla (1.85 tai uudempi): git clone https://github.com/janttsu/varsto.git tai pura arkisto, sitten cargo build --release; ohjelmatiedosto on target/release/varsto. cargo test --workspace ajaa testisarjan, mukaan lukien kahden laitteen skenaariot.

Työpöytäkäyttöliittymä

Linuxissa ja Windowsissa oletus on varsto tray: ilmoitusalueen kuvake, josta voi avata ja keskeyttää ja josta löytyy asennuskohta, kun uudempi versio on saatavilla; taustapalvelu synkronoi muutokset sekunneissa itsestään. varsto desktop käynnistää pienen verkkopalvelimen, joka kuuntelee osoitteessa 127.0.0.1 satunnaisessa portissa, tulostaa kertakäyttöisen linkin istuntotunnisteineen ja avaa sen oletusselaimessasi. Siihen pääsevät vain tämän tietokoneen ohjelmat; sivu hylkää pyynnöt, joissa ei ole tunnistetta, sekä pyynnöt, joiden Host-otsake ei ole paikallinen osoite. Käyttöliittymästä voit luoda holvin tai liittyä holviin, lisätä tallennuspaikkoja ja kansioita, jakaa, asettaa säilytyssääntöjä ja listata kaksoiskappaleita; synkronointi, tarkistus ja korjaus toimivat itsestään. Sovelluspaketti ja Varsto Desktop.cmd tekevät täsmälleen tämän.

Pika-aloitus (komentorivi)

export VARSTO_PASSPHRASE='a long passphrase'
varsto --home ~/.varsto-laptop init --name laptop            # prints the vault key once; keep it offline
varsto --home ~/.varsto-laptop storage add-local box /mnt/box
varsto --home ~/.varsto-laptop folder add docs ~/Documents/synced
varsto --home ~/.varsto-laptop sync

# another device that can reach the same storage
varsto --home ~/.varsto-desk join --name desk --vault-key <hex> --storage-path /mnt/box
varsto --home ~/.varsto-desk folder attach docs ~/synced
varsto --home ~/.varsto-desk sync
varsto --home ~/.varsto-desk status --json
varsto --home ~/.varsto-desk fsck --verify

Holviavain on pääavain heksamuodossa. Jos menetät sen ja kaikki laitteesi, menetät datan: tiliä tai avaimen talletusta ei ole.
