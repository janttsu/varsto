Kuvakaappaukset

Kuvattu automaattisesti versiosta 0.0.1-alpha.13 (commit c7e436c) 2026-10-13, GitHub Actions -ajo 117. Jokainen GitHub Actions -käännös ottaa nämä kuvat uudelleen puhtailla koneilla (Linux, Windows, macOS, Android-emulaattori ja iOS Simulator) keksityllä esittelyholvilla: kannettava, jolla on kaksi kansiota, ja puhelin, jolla kuvakansio on valikoivassa tilassa. Työpöydän käyttöliittymä on sama sivu Linuxissa, macOS:ssä ja Windowsissa: taustapalvelu tarjoaa sen ja selaimesi piirtää sen, joten vain ikkunan kehys eroaa: Linuxissa ja Windowsissa sen piirtää selaimesi, macOS:ssä sovelluksen oma ikkuna.
