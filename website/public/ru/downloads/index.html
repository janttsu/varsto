К содержанию
Альфа-версия, не для рабочих данных. Ошибки могут уничтожить данные, формат хранения может измениться без средства переноса, а шифрование ещё не проверяли. Храни собственные резервные копии и убедись, что из них можно восстановиться.

Загрузки

Посмотри снимки экрана, чтобы увидеть, как выглядит альфа.

Нужна самая новая сборка для разработки? Ежедневные сборки не подписаны и не для рабочих данных.

Один пакет на платформу: фоновая служба, интерфейс и та же командная строка внутри. В Linux и macOS служба стартует при входе (пользовательский unit systemd или launch agent), в Windows её запускает приложение в трее. В Linux и Windows интерфейс открывается в браузере; в macOS у нативного приложения своё окно. Альфа: используй только с тестовыми данными и храни свои резервные копии.

Android. APK подписан для выпуска новым ключом, поэтому следующие выпуски ставятся поверх как обновление. Прежний debug-APK (alpha.15 или более старая ежедневная сборка) обновить до него нельзя: сначала удали старое приложение. Это удаляет копию хранилища на этом устройстве, поэтому убедись, что хранилище есть на другом устройстве или в хранилище данных, и затем ставь новый APK.

Список загрузок на английском.

Альфы нет в магазине приложений. Сверь файл со списком контрольных сумм, подписанным ключом выпуска. Подписи кода Apple и Microsoft ещё нет, поэтому macOS и Windows предупреждают при установке. Пакет Android подписан собственным ключом проекта.

Verify your download

SHA256SUMS is signed with the Varsto release key (SHA256SUMS.sig, minisign format). The key is kept offline, built into every varsto binary and published in the repository and here; key ID 2861CE1D220B07F3:

RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF

With Varsto already installed, put SHA256SUMS and SHA256SUMS.sig next to the download (or leave them out to fetch them) and run

varsto verify-release varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz --github

--github also compares the checksum with the list attached to the GitHub release, a second channel. Without Varsto, use minisign and then check the hash:

minisign -Vm SHA256SUMS -x SHA256SUMS.sig -P RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF
sha256sum -c --ignore-missing SHA256SUMS

varsto update does all of this by itself and refuses an update whose signature or checksum does not match.

iOS. Пакет iOS — неподписанный .ipa. Из одного файла он не ставится. AltStore, SideStore или Sideloadly подписывает его твоим Apple ID и устанавливает. У Varsto нет подписи разработчика Apple. Ошибка Sideloadly про подпись, Apple ID, который не может подписать ещё приложения, просроченная установка в обход магазина или устройство, которое не доверяет разработчику, идут от этого инструмента или от Apple, а не от сломанного пакета. Именно этот файл эти инструменты и ставят. Приложение собрано в CI и ещё не запускалось на настоящем устройстве. Исходный код оболочки лежит в apps/ios на GitHub.

Файловые менеджеры Linux. varsto install регистрирует тип заполнителя. В Файлах Ubuntu (Nautilus) и в Nemo Linux Mint двойной щелчок по .varsto-placeholder скачивает файл и открывает его. Nautilus получает ещё два скрипта, Скачать и Освободить место. Nemo получает те же два действия в меню правой кнопки. Скачивание приносит файл на этот компьютер. Освобождение места возвращает заполнитель и оставляет копии в твоём хранилище данных. Это выборочная синхронизация.

Установка и проверка

curl -O https://varsto.net/downloads/SHA256SUMS
curl -O https://varsto.net/downloads/varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz
sha256sum -c SHA256SUMS --ignore-missing
tar xzf varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz
cd varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl
./varsto desktop        # opens the desktop interface in your browser
./varsto --help         # command line

Сборка из исходников

Исходный код лежит по адресу github.com/janttsu/varsto. Каждый выпуск — это тег там, и к выпуску GitHub приложены те же файлы; архив исходников ниже ему соответствует. Со стабильным набором инструментов Rust (1.85 или новее): git clone https://github.com/janttsu/varsto.git или распакуй архив, затем cargo build --release. Бинарный файл — target/release/varsto. cargo test --workspace запускает набор тестов, включая сценарии с двумя устройствами.

Интерфейс рабочего стола

В Linux и Windows по умолчанию varsto tray: значок в трее, из которого можно открыть и поставить на паузу, и пункт установки, когда есть версия новее. Фоновая служба сама синхронизирует изменения за несколько секунд. varsto desktop запускает небольшой веб-сервер, который слушает 127.0.0.1 на случайном порту, печатает одноразовую ссылку с токеном сеанса и открывает её в браузере по умолчанию. До него доходят только программы этого компьютера. Страница отвергает запросы без токена и запросы, у которых заголовок Host — не локальный адрес. Из интерфейса можно создать хранилище или присоединиться к нему, добавить хранилища данных и папки, дать общий доступ, задать правила хранения и показать дубликаты. Синхронизация, проверка и починка идут сами. Пакет приложения и Varsto.cmd делают ровно это.

Быстрый старт (командная строка)

export VARSTO_PASSPHRASE='a long passphrase'
varsto --home ~/.varsto-laptop init --name laptop            # prints the vault key once; keep it offline
varsto --home ~/.varsto-laptop storage add-local box /mnt/box
varsto --home ~/.varsto-laptop folder add docs ~/Documents/synced
varsto --home ~/.varsto-laptop sync

# another device that can reach the same storage
varsto --home ~/.varsto-desk join --name desk --vault-key <hex> --storage-path /mnt/box
varsto --home ~/.varsto-desk folder attach docs ~/synced
varsto --home ~/.varsto-desk sync
varsto --home ~/.varsto-desk status --json
varsto --home ~/.varsto-desk fsck --verify

Ключ хранилища — главный ключ в шестнадцатеричном виде. Потеряешь его и все устройства — потеряешь данные: учётной записи нет, и ключи никто не хранит за тебя.
