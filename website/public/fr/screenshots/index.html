Captures d’écran

Capturées automatiquement depuis la version 0.0.1-alpha.16 (commit 64346c5) le 2026-11-04, exécution GitHub Actions 343. Chaque build sur GitHub Actions reprend ces images sur des machines neuves (Linux, Windows, macOS, l’émulateur Android et le simulateur iOS), avec un coffre de démonstration inventé : un portable avec deux dossiers et un téléphone qui conserve le dossier de photos en mode sélectif. L’interface de bureau est la même page sous Linux, macOS et Windows : elle est servie par le service en arrière-plan et affichée par votre navigateur, donc seul le cadre de la fenêtre diffère : sous Linux et Windows, c’est votre navigateur qui l’affiche, sous macOS la fenêtre propre à l’application.
