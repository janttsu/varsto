Téléchargements

Consultez les captures d’écran pour voir à quoi ressemble l’alpha.

Vous voulez la version de développement la plus récente ? Les versions quotidiennes ne sont pas signées et ne conviennent pas à des données de production.

Un paquet par plateforme, avec le service en arrière-plan, l’interface et la même ligne de commande à l’intérieur ; sous Linux et macOS, le service démarre à l’ouverture de session (une unité utilisateur systemd ou un launch agent), sous Windows il est lancé par l’application de la zone de notification. Sous Linux et Windows, l’interface s’ouvre dans votre navigateur ; sous macOS, l’application native a sa propre fenêtre. Alpha : à utiliser uniquement avec des données de test, en conservant vos propres sauvegardes.

Android. L’APK est signé pour la publication avec une nouvelle clé, de sorte que les versions suivantes s’installent par-dessus comme une mise à jour. Un ancien APK de débogage (alpha.15 ou une version quotidienne plus ancienne) ne peut pas être mis à jour vers celui-ci : désinstallez d’abord l’ancienne application, ce qui supprime la copie du coffre de cet appareil, donc assurez-vous que le coffre existe sur un autre appareil ou un stockage, puis installez le nouvel APK.

iOS : ipa non signé, AltStore, SideStore et Sideloadly

Le paquet iOS est un .ipa non signé. Il ne s’installe pas à partir du seul fichier. AltStore, SideStore ou Sideloadly le signe avec votre propre identifiant Apple et l’installe. Varsto n’a pas de signature de développeur Apple. Une erreur Sideloadly sur la signature, un identifiant Apple qui ne peut plus signer d’applications, une installation expirée ou un appareil qui ne fait pas confiance au développeur vient de cet outil ou d’Apple, pas d’un paquet cassé. C’est ce fichier que ces outils installent. L’application a été compilée en CI et n’a pas été exécutée sur un vrai appareil. Le code de la coque est dans apps/ios sur GitHub.

La liste des téléchargements est en anglais.

L'alpha n'est pas dans une boutique d'applications. Vérifiez le fichier avec la liste de sommes signée par la clé de publication. La signature de code Apple et Microsoft n'est pas encore en place, donc macOS et Windows avertissent à l'installation. Le paquet Android est signé avec la clé du projet.

Verify your download

SHA256SUMS is signed with the Varsto release key (SHA256SUMS.sig, minisign format). The key is kept offline, built into every varsto binary and published in the repository and here; key ID 2861CE1D220B07F3:

RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF

With Varsto already installed, put SHA256SUMS and SHA256SUMS.sig next to the download (or leave them out to fetch them) and run

varsto verify-release varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz --github

--github also compares the checksum with the list attached to the GitHub release, a second channel. Without Varsto, use minisign and then check the hash:

minisign -Vm SHA256SUMS -x SHA256SUMS.sig -P RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF
sha256sum -c --ignore-missing SHA256SUMS

varsto update does all of this by itself and refuses an update whose signature or checksum does not match.

Installer et vérifier

curl -O https://varsto.net/downloads/SHA256SUMS
curl -O https://varsto.net/downloads/varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz
sha256sum -c SHA256SUMS --ignore-missing
tar xzf varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz
cd varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl
./varsto desktop        # opens the desktop interface in your browser
./varsto --help         # command line

Compiler depuis les sources

Le code source se trouve sur github.com/janttsu/varsto ; chaque version y est une étiquette, avec les mêmes fichiers joints à sa version GitHub, et l’archive des sources ci-dessous lui correspond. Avec une chaîne d’outils Rust stable (1.85 ou plus récente) : git clone https://github.com/janttsu/varsto.git ou décompressez l’archive, puis cargo build --release ; le binaire est target/release/varsto. cargo test --workspace lance la suite de tests, y compris les scénarios à deux appareils.

Interface de bureau

Sous Linux et Windows, le mode par défaut est varsto tray : une icône dans la zone de notification avec ouvrir et mettre en pause, et un élément d’installation lorsqu’une version plus récente existe ; le service en arrière-plan synchronise seul les changements en quelques secondes. varsto desktop démarre un petit serveur web lié à 127.0.0.1 sur un port aléatoire, affiche un lien à usage unique contenant un jeton de session et l’ouvre dans votre navigateur par défaut. Seuls les programmes de cet ordinateur peuvent y accéder ; la page refuse les requêtes sans le jeton et celles dont l’en-tête Host n’est pas l’adresse locale. Depuis l’interface, vous pouvez créer ou rejoindre un coffre, ajouter des stockages et des dossiers, partager, définir des politiques et lister les doublons ; la synchronisation, la vérification et la réparation s’exécutent d’elles-mêmes. Le bundle de l’application et Varsto.cmd font exactement cela.

Démarrage rapide (ligne de commande)

export VARSTO_PASSPHRASE='a long passphrase'
varsto --home ~/.varsto-laptop init --name laptop            # prints the vault key once; keep it offline
varsto --home ~/.varsto-laptop storage add-local box /mnt/box
varsto --home ~/.varsto-laptop folder add docs ~/Documents/synced
varsto --home ~/.varsto-laptop sync

# another device that can reach the same storage
varsto --home ~/.varsto-desk join --name desk --vault-key <hex> --storage-path /mnt/box
varsto --home ~/.varsto-desk folder attach docs ~/synced
varsto --home ~/.varsto-desk sync
varsto --home ~/.varsto-desk status --json
varsto --home ~/.varsto-desk fsck --verify

La clé du coffre est la clé maîtresse en hexadécimal. La perdre, ainsi que tous vos appareils, revient à perdre les données : il n’y a ni compte ni séquestre.
