Versions quotidiennes

Ce sont des versions de développement issues de la branche principale, pas des versions officielles.

  • Elles ne sont pas signées et n’ont subi aucun test de publication. Ne les utilisez pas pour des données de production.
  • Le format de stockage peut changer d’une version à l’autre sans aucune migration. Le format 2 exigera de recréer les coffres.
  • varsto update ne les installe jamais et ne consulte pas cette page. Pour passer à une version quotidienne plus récente, téléchargez-la de nouveau.
  • Conservez vos propres sauvegardes.

Vous cherchez quelque chose de fiable ? Utilisez plutôt les téléchargements stables.

Vérifier

Placez SHA256SUMS à côté des fichiers téléchargés (les noms du tableau sont les noms fixes) et exécutez

sha256sum -c SHA256SUMS --ignore-missing

Omettez --ignore-missing si vous avez téléchargé tous les fichiers. Cette liste n’est pas signée ; elle montre seulement qu’un téléchargement est complet et intact.

Lacunes connues

  • Rien n’est signé : ni signature de version, ni signature de code Apple ou Microsoft. Les sommes de contrôle ne détectent qu’un téléchargement corrompu.
  • Le format 2 (la refonte des enregistrements) n’est pas inclus ; lorsqu’il arrivera, les coffres créés avec ces versions devront être recréés.
  • macOS, Windows et iOS avertissent à propos des logiciels non signés ; sous macOS, ouvrez par clic droit puis Ouvrir, sous Windows SmartScreen demande une confirmation.
  • Le programme d’installation Windows n’a subi qu’un test de fumée en CI (installation, mise à jour, réparation, refus de rétrogradation, désinstallation), pas sur une vraie machine.
  • L’ipa iOS n’a pas été exécuté sur un vrai appareil. Installez-le avec AltStore, SideStore ou Sideloadly.
  • Certains textes de l’interface de l’application ne sont pas encore traduits ; ils sont consignés dans les journaux.
