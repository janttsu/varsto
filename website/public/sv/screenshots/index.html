Skärmbilder

Tagna automatiskt från version 0.0.1-alpha.13 (commit c7e436c) den 2026-10-13, GitHub Actions-körning 117. Varje bygge på GitHub Actions tar de här bilderna på nytt på nyinstallerade maskiner (Linux, Windows, macOS, Android-emulatorn och iOS-simulatorn), med ett påhittat demovalv: en bärbar dator med två mappar och en telefon som har fotomappen i selektivt läge. Skrivbordsgränssnittet är samma sida på Linux, macOS och Windows: den serveras av bakgrundstjänsten och renderas av din webbläsare, så bara fönsterramen skiljer sig: på Linux och Windows renderar din webbläsare den, på macOS gör appens eget fönster det.
