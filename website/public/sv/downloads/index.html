Nedladdningar

Se skärmbilderna för att se hur alfaversionen ser ut.

Vill du ha det senaste utvecklingsbygget? De dagliga byggena är osignerade och inte för produktionsdata.

Ett paket per plattform med bakgrundstjänsten, gränssnittet och samma kommandorad; på Linux och macOS startar tjänsten vid inloggning (en systemd-användarenhet eller en launch agent), på Windows körs den av appen i systemfältet. På Linux och Windows öppnas gränssnittet i din webbläsare; på macOS har den inbyggda appen ett eget fönster. Alfa: använd den bara med testdata och behåll egna säkerhetskopior.

Android. APK:n är signerad för release med en ny nyckel, så senare versioner installeras över den som en uppdatering. En tidigare debug-APK (alpha.15 eller ett äldre dagligt bygge) kan inte uppdateras till den: avinstallera den gamla appen först, vilket tar bort enhetens kopia av valvet, så se till att valvet finns på en annan enhet eller en lagringsplats, och installera sedan den nya APK:n.

iOS: osignerad ipa, AltStore, SideStore och Sideloadly

iOS-paketet är en osignerad .ipa. Den installeras inte från filen ensam. AltStore, SideStore eller Sideloadly signerar den med ditt eget Apple-ID och installerar den. Varsto har ingen Apple-utvecklarsignatur. Ett Sideloadly-fel om signering, ett Apple-ID som inte kan signera fler appar, en installation som har gått ut, eller en enhet som inte litar på utvecklaren kommer från det verktyget eller från Apple, inte från ett trasigt paket. Samma fil är den som verktygen installerar. Appen har byggts i CI och har inte körts på en riktig enhet. Skalets källa ligger i apps/ios på GitHub.

Verify your download

SHA256SUMS is signed with the Varsto release key (SHA256SUMS.sig, minisign format). The key is kept offline, built into every varsto binary and published in the repository and here; key ID 2861CE1D220B07F3:

RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF

With Varsto already installed, put SHA256SUMS and SHA256SUMS.sig next to the download (or leave them out to fetch them) and run

varsto verify-release varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz --github

--github also compares the checksum with the list attached to the GitHub release, a second channel. Without Varsto, use minisign and then check the hash:

minisign -Vm SHA256SUMS -x SHA256SUMS.sig -P RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF
sha256sum -c --ignore-missing SHA256SUMS

varsto update does all of this by itself and refuses an update whose signature or checksum does not match.

Bygg från källkod

Källkoden finns på github.com/janttsu/varsto; varje release är en tagg där, med samma filer bifogade till sin GitHub-release, och källkodsarkivet nedan motsvarar den. Med en stabil Rust-verktygskedja (1.85 eller nyare): git clone https://github.com/janttsu/varsto.git eller packa upp arkivet, och sedan cargo build --release; den körbara filen är target/release/varsto. cargo test --workspace kör testsviten, inklusive scenarierna med två enheter.

Skrivbordsgränssnitt

På Linux och Windows är standard varsto tray: en ikon i systemfältet med öppna och pausa, och ett installationsval när en nyare version finns; bakgrundstjänsten synkroniserar ändringar inom några sekunder på egen hand. varsto desktop startar en liten webbserver bunden till 127.0.0.1 på en slumpmässig port, skriver ut en engångslänk med en sessionstoken och öppnar den i din standardwebbläsare. Bara program på den här datorn når den; sidan avvisar förfrågningar utan token och förfrågningar vars Host-huvud inte är den lokala adressen. I gränssnittet kan du skapa eller ansluta till ett valv, lägga till lagringsplatser och mappar, dela, ställa in regler och lista dubbletter; synkronisering, verifiering och reparation sköts automatiskt. Appaketet och Varsto.cmd gör precis detta.

Snabbstart (kommandorad)

export VARSTO_PASSPHRASE='a long passphrase'
varsto --home ~/.varsto-laptop init --name laptop            # prints the vault key once; keep it offline
varsto --home ~/.varsto-laptop storage add-local box /mnt/box
varsto --home ~/.varsto-laptop folder add docs ~/Documents/synced
varsto --home ~/.varsto-laptop sync

# another device that can reach the same storage
varsto --home ~/.varsto-desk join --name desk --vault-key <hex> --storage-path /mnt/box
varsto --home ~/.varsto-desk folder attach docs ~/synced
varsto --home ~/.varsto-desk sync
varsto --home ~/.varsto-desk status --json
varsto --home ~/.varsto-desk fsck --verify

Valvnyckeln är huvudnyckeln i hex. Förlorar du den och alla enheter förlorar du dina data: det finns inget konto och ingen deponering.
