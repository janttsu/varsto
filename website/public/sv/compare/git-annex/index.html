Varsto och git-annex

git-annex hanterar stora filer med git utan att lagra deras innehåll i git. Det är ett kraftfullt verktyg för tekniska användare som arkiverar, säkerhetskopierar och flyttar data mellan många diskar och fjärrlagringar, och det är Varstos närmaste släkting på den här listan.

Så fungerar git-annex

Varje repository kan finnas på valfri maskin eller disk, och ”special remotes” når S3 och kompatibla lagringar, rclone, rsync, vanliga eller flyttbara kataloger, WebDAV med mera. En git-gren registrerar vilket repository som har varje fil (”git annex whereis”), och numcopies vägrar ta bort innehåll om det inte finns tillräckligt många verifierade kopior på andra ställen. Kryptering är valfri för varje special remote och använder GnuPG; filnamnen i själva git-repositoryt förblir synliga om inte gcrypt används. Det är främst ett kommandoradsverktyg; det finns en enklare assistent, Android fungerar via Termux, och det finns ingen iOS-app.

Vilken passar

git-annex

Välj git-annex när du är van vid git och kommandoraden, vill ha maximal kontroll och insyn och värdesätter ett moget verktyg som är fri programvara framför en färdig app.

Varsto

Varsto vill ge samma garantier (varje kopia redovisad, regler för hur många kopior som måste finnas, flyttbara diskar som kommer och går) till människor som inte använder git: kontinuerlig synkronisering i bakgrunden, ett gränssnitt för dator och telefon, kryptering som alltid omfattar både namn och innehåll, peer-to-peer-överföring och delning med andra.

Varsto är alfaprogramvara: anförtro den inga data som du inte har någon annan kopia av, och dess kryptografi har inte granskats av någon oberoende part. De andra produkterna här är mogna. Uppgifterna om dem kontrollerades i deras egen dokumentation i oktober 2026; priser och abonnemang ändras ofta, så se deras egna sidor för aktuella siffror. Rättelser tas gärna emot på forumet eller på GitHub.
