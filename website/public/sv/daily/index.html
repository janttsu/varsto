Dagliga byggen

Det här är utvecklingsbyggen från huvudgrenen, inte releaser.

  • De är inte releaser och har inte gått igenom någon releasetestning. De saknar releasesignatur och kodsignering från Apple eller Microsoft. Använd dem inte för produktionsdata.
  • Lagringsformatet kan ändras mellan byggen utan någon migrering. Format 2 kommer att kräva att valv skapas på nytt.
  • varsto update --daily installerar det senaste dagliga bygget för din plattform (kommandoradsbyggena för Linux och Windows; macOS-appen och Android-APK:n installeras för hand). Vanliga varsto update håller sig till releaser och installerar aldrig ett dagligt bygge.
  • Behåll egna säkerhetskopior.

Verifiera

Lägg SHA256SUMS bredvid filerna du laddade ner (filnamnen i tabellen är de fasta namnen) och kör

sha256sum -c SHA256SUMS --ignore-missing

Utelämna --ignore-missing om du laddade ner alla filer. Listan är signerad med den separata dagliga nyckeln (SHA256SUMS.sig, minisign-format; nyckeln är daily-key.pub), och det är den som varsto update --daily kontrollerar. Förutom att en nedladdning är komplett och oskadd visar signaturen att listan kommer från projektets egen bygglinje.

Kända brister

  • Byggena har ingen releasesignatur och ingen kodsignering från Apple eller Microsoft. Kontrollsummelistan är signerad med den separata dagliga nyckeln (varsto update --daily kontrollerar den), vilket visar att ett bygge kommer från projektets CI, inte att det har testats.
  • macOS, Windows och iOS varnar för osignerad programvara; på macOS öppnar du med högerklick och Öppna, på Windows ber SmartScreen om bekräftelse.
  • Windows-installationsprogrammet har bara röktestats i CI (installation, uppgradering, reparation, nekad nedgradering, avinstallation), inte på en riktig dator.
  • iOS-ipa:n har inte körts på en riktig enhet. Installera den med AltStore, SideStore eller Sideloadly.
  • Vissa texter i appens gränssnitt är ännu inte översatta; de loggas.
  • Windows and iOS are still from the previous build 20261016-316c579; they were not rebuilt this round.
  • The grace period before a storage that has fallen behind is given up (package E) defaults to 30 days.
  • The Kotlin, Swift and Windows full-screen code and the pairing fix have not been verified on real devices.
  • The first update with --daily needs a binary that already contains the feature, so install this build by hand once; after that varsto update --daily can take over.
