Security policy

From SECURITY.md in the repository, rendered 2026-10-14.

Varsto is alpha software and the cryptography has not been independently audited. See the warning in README.md.

Reporting a vulnerability

Please do not open a public issue for security problems.

A dedicated security contact is not available yet (2026-10-13); until then, report privately through GitHub's private vulnerability reporting on the repository.

Scope

In scope: the core library, the CLI, the desktop and mobile apps, the storage format and protocols, the MCP server, the website and the release process.

Threat model

The threat model in docs/architecture/threat-model.md is a design-stage model written before the code; much of it is now implemented as 0.0.1-alpha.13, and its per-row status notes and docs/spec/alpha-0-format.md record what is built. Nothing has been audited, so treat every guarantee as unproven.
