Sieh in den Screenshots, wie die Alpha aussieht.

Willst du den neuesten Entwicklungs-Build? Die täglichen Builds sind unsigniert und nicht für Produktionsdaten.

Ein Paket je Plattform, darin der Hintergrunddienst, die Oberfläche und dieselbe Kommandozeile; unter Linux und macOS startet der Dienst bei der Anmeldung (eine systemd-User-Unit oder ein Launch Agent), unter Windows führt ihn die Infobereich-App. Unter Linux und Windows öffnet sich die Oberfläche in deinem Browser; unter macOS hat die native App ein eigenes Fenster. Alpha: benutze sie nur mit Testdaten und behalte deine eigenen Sicherungen.

Android. Die APK ist für die Veröffentlichung unter einem neuen Schlüssel signiert, sodass spätere Veröffentlichungen als Update darüber installiert werden. Eine frühere Debug-APK (alpha.15 oder ein älterer täglicher Build) lässt sich nicht darauf aktualisieren: deinstalliere zuerst die alte App, was die Tresorkopie dieses Geräts entfernt. Stell also sicher, dass der Tresor noch auf einem anderen Gerät oder einem Speicher liegt, und installiere dann die neue APK.

iOS: unsignierte ipa, AltStore, SideStore und Sideloadly

Das iOS-Paket ist eine unsignierte .ipa. Sie lässt sich nicht aus der Datei allein installieren. AltStore, SideStore oder Sideloadly signieren sie mit deiner eigenen Apple ID und installieren sie. Varsto hat keine Entwickler-Signatur von Apple. Ein Fehler von Sideloadly zur Signatur, eine Apple ID, die keine weiteren Apps signieren kann, ein abgelaufenes Sideload oder ein Gerät, das dem Entwickler nicht vertraut, kommt von diesem Werkzeug oder von Apple, nicht von einem defekten Paket. Dieselbe Datei ist es, die diese Werkzeuge installieren. Die App wurde in CI gebaut und ist noch nicht auf einem echten Gerät gelaufen. Der Quellcode der Hülle liegt in apps/ios auf GitHub.

Die Alpha ist nicht in einem App Store. Prüfe die Datei gegen die mit dem Veröffentlichungsschlüssel signierte Prüfsummenliste. Verify your download

SHA256SUMS is signed with the Varsto release key (SHA256SUMS.sig, minisign format). The key is kept offline, built into every varsto binary and published in the repository and here; key ID 2861CE1D220B07F3:

RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF

With Varsto already installed, put SHA256SUMS and SHA256SUMS.sig next to the download (or leave them out to fetch them) and run

varsto verify-release varsto-0.0.1-alpha.16-x86_64-unknown-linux-musl.tar.gz --github

--github also compares the checksum with the list attached to the GitHub release, a second channel. Without Varsto, use minisign and then check the hash:

minisign -Vm SHA256SUMS -x SHA256SUMS.sig -P RWTzBwsiHc5hKJfkPOF6AQQWdIOHE1jf/UMs/GUCoOqocAJftz915FBF
sha256sum -c --ignore-missing SHA256SUMS

varsto update does all of this by itself and refuses an update whose signature or checksum does not match.

Aus dem Quellcode bauen

Der Quellcode liegt unter github.com/janttsu/varsto; jede Veröffentlichung ist dort ein Tag, an dessen GitHub-Release dieselben Dateien hängen, und das Quellarchiv unten entspricht ihm. Mit einer stabilen Rust-Toolchain (1.85 oder neuer): git clone https://github.com/janttsu/varsto.git oder das Archiv auspacken, dann cargo build --release; die Programmdatei ist target/release/varsto. cargo test --workspace führt die Testsuite aus, einschließlich der Szenarien mit zwei Geräten.

Desktop-Oberfläche

Unter Linux und Windows ist die Voreinstellung varsto tray: ein Symbol im Infobereich mit Öffnen und Pause und einem Eintrag zum Installieren, wenn eine neuere Version da ist; der Hintergrunddienst synchronisiert Änderungen innerhalb von Sekunden von selbst. varsto desktop startet einen kleinen Webserver, gebunden an 127.0.0.1 auf einem zufälligen Port, gibt einen Einmallink mit einem Sitzungs-Token aus und öffnet ihn in deinem Standardbrowser. Nur Programme auf diesem Rechner erreichen ihn; die Seite lehnt Anfragen ohne das Token ab und Anfragen, deren Host-Header nicht die lokale Adresse ist. Aus der Oberfläche kannst du einen Tresor anlegen oder einem beitreten, Speicher und Ordner hinzufügen, freigeben, Aufbewahrungsregeln setzen und Duplikate auflisten; Synchronisierung, Prüfung und Reparatur laufen von selbst. Das App-Bundle und Varsto.cmd tun genau das.

Schnellstart (Kommandozeile)

export VARSTO_PASSPHRASE='a long passphrase'
varsto --home ~/.varsto-laptop init --name laptop            # prints the vault key once; keep it offline
varsto --home ~/.varsto-laptop storage add-local box /mnt/box
varsto --home ~/.varsto-laptop folder add docs ~/Documents/synced
varsto --home ~/.varsto-laptop sync

# another device that can reach the same storage
varsto --home ~/.varsto-desk join --name desk --vault-key <hex> --storage-path /mnt/box
varsto --home ~/.varsto-desk folder attach docs ~/synced
varsto --home ~/.varsto-desk sync
varsto --home ~/.varsto-desk status --json
varsto --home ~/.varsto-desk fsck --verify

Der Tresorschlüssel ist der Hauptschlüssel in Hex. Ihn und jedes Gerät zu verlieren heißt, die Daten zu verlieren: es gibt kein Konto und keine Hinterlegung.
