Bildschirmfotos

Automatisch aufgenommen von Version 0.0.1-alpha.16 (commit 64346c5) am 2026-11-04, GitHub-Actions-Lauf 343. Jeder Build auf GitHub Actions nimmt diese Bilder erneut auf frischen Rechnern auf (Linux, Windows, macOS, der Android-Emulator und der iOS Simulator), mit einem erfundenen Demo-Tresor: ein Laptop mit zwei Ordnern und ein Telefon, das den Foto-Ordner im selektiven Modus hat. Die Desktop-Oberfläche ist auf Linux, macOS und Windows dieselbe Seite: der Hintergrunddienst liefert sie aus, und dein Browser zeichnet sie, sodass sich nur der Fensterrahmen unterscheidet. Unter Linux und Windows zeichnet sie dein Browser, unter macOS das eigene Fenster der App.
