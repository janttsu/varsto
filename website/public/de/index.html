Bring deinen eigenen Speicher mit. Behalte deine eigenen Schlüssel. Wisse, wo jeder Block ist.

Ein NAS, ein Bucket, den du schon bezahlst, Platten in einer Schublade. Varsto hält dort verschlüsselte Kopien und sagt dir, wenn eine Datei zu wenige hat, bevor du es merkst, weil du sie brauchst. Kein Konto; die Dateien liegen nur auf Speichern, die du selbst wählst.

So funktioniert es Im Vergleich zu Syncthing

Warum du es wollen würdest

Du willst wissen, dass eine Kopie wirklich da ist

Jedes Gerät signiert, was es gespeichert und was es geprüft hat. Eine Regel wie „eine zu Hause, eine woanders, in diesem Monat geprüft“ warnt, wenn sie nicht mehr stimmt. Buchführung und Regeln.

Den Speicher hast du schon

Ein Ordner auf diesem Rechner, ein NAS, ein S3-Bucket, ein rclone-Ziel. Sie sehen Geheimtext und Größen, nie Namen oder Inhalt. Kein Konto, das du anlegen müsstest. Dein eigener Speicher.

Eine Platte in der Schublade soll zählen

Docke eine Platte an, lass sie sich mit dem füllen, das die wenigsten Kopien hat, und wirf sie aus, wenn sie sagt, dass es sicher ist. Wenn sie zurückkommt, zählt sie weiter als Kopie zu Hause. Plattenpools.

Ein verlorener Laptop soll nicht das Ende sein

Die Schlüssel bleiben auf deinen Geräten, die Wiederherstellungswörter auf Papier. Du entfernst ein verlorenes Gerät, und die anderen machen weiter. Das NAS eines anderen kann Kopien halten, die es nicht lesen kann. Kopien, die nicht lesen können.

Das ist eine Alpha, und weder der Entwurf noch der Code ist geprüft. Wie die Verschlüsselung funktioniert, das Bedrohungsmodell (auf Englisch) und was sich in dieser Version geändert hat. Die Builds liegen auf der Download-Seite.

Zuletzt aus dem Blog

  • 2026-11-22 Alpha.17: der Tresor bleibt, die stillen Fehler gehen
    Kein neues Speicherformat und keine neuen Wörter zum Aufschreiben. Alpha.17 ist die Version, die eine fehlgeschlagene Synchronisierung davon abhält, Dateien zu löschen, die letzte Sicherung behält und deinem Telefon sagt, wenn wirklich etwas nicht stimmt.
  • 2026-11-04 Alpha.16: Speicherformat 3, Ordnerzugriff nach Genehmigung und ein Rendezvous-Dienst
    Ein neues Speicherformat mit einem Hauptbuch auf Paketebene, signierten Datensätzen und Wiederherstellungswörtern, sodass vorhandene Tresore neu angelegt werden müssen; Ordner werden einem Gerät durch die Genehmigung eines Eigentümers geöffnet; Geräte finden einander über einen optionalen Rendezvous-Dienst; Beitritt und Mitgliedschaftsänderungen funktionieren offline; und Importe aus Torrents und YouTube.
  • 2026-10-16 Alpha.15: Speicherformat 2, ein Windows-Installationsprogramm und ein täglicher Kanal
    Ein neues Speicherformat, das zwei Funde der Sicherheitsprüfung behebt, sodass vorhandene Tresore neu angelegt werden müssen; Windows bekommt ein Setup-Programm, ein natives Fenster und automatische Aktualisierungen; und ein signierter Kanal für tägliche Builds.
  • 2026-10-14 Alpha.14: eine Sicherheitsprüfung, ihre Korrekturen, und alles, was seit alpha.13 zusammengeführt wurde
    Eine Sicherheitsprüfung des ganzen Programms auf Code-Ebene, die Korrekturen, die sie verlangt hat, eine viel schnellere Synchronisierung, fortsetzbare Verschiebungen auf einen Stapel Wechselplatten, und die rund zwanzig Funktionen, die seit alpha.13 auf dem Hauptzweig gewartet hatten.
  • 2026-10-13 Alpha.13: Sicherungen, die nichts ändern kann
    Wähle einen Ordner auf einem beliebigen Gerät, und Varsto behält verschlüsselte, schreibgeschützte Schnappschüsse davon auf deinen externen Speichern, nie auf deinen Geräten, so viele Tage, wie du wählst (standardmäßig 90). Wiederherstellungen gehen in ein Verzeichnis, das du nennst, aus der App oder von der Kommandozeile.
  • 2026-10-12 Alpha.12: kleine Dateien in Paketen, und Varsto auf Finnisch und Schwedisch
    Kleine verschlüsselte Blöcke werden jetzt in Paketen geschrieben, sodass ein Ordner mit 20.000 kleinen Dateien auf einem Bucket 79 Objekte wird statt 20.000. Oberfläche, Infobereich, Menüleiste, mobile Hüllen und diese Website gibt es auf Finnisch und Schwedisch wie auf Englisch.
  • 2026-10-10 Alpha.9: Daten, wo du sie haben willst, Reparatur von selbst, signierte Aktualisierungen, und jede Plattform öffentlich gebaut
    Ordner lassen sich auf gewählte Speicher legen und zwischen ihnen verschieben, verlorene Kopien werden von selbst repariert, Aktualisierungen sind mit einem Offline-Schlüssel signiert, Downloads von Gegenstelle zu Gegenstelle holen viele Blöcke auf einmal, und jedes Paket wird jetzt auf den Runnern von GitHub gebaut, getestet und fotografiert.
  • 2026-10-09 Alpha.8: ein Hauptbuch, das klein bleibt, Geräte, die sich entfernen lassen, und Telefone, die nichts im Klartext behalten
    Das Hauptbuch listet jetzt nur, was neu ist, hält eine zwischengespeicherte Sicht und stutzt sich hinter signierten Prüfpunkten; Geräte lassen sich entfernen, mit neuen Schlüsseln für alles, was danach geschrieben wird; Telefone halten verschlüsselte Ordner als verschlüsselte Blöcke; und die Oberfläche zeigt, wo deine Daten sind und wie der Verkehr zwischen Gegenstellen fließt.
  • 2026-10-09 Alpha.7: Geräte mit einem Code koppeln, Finder-Aktionen und ein echter NAT-Weg
    Geräte koppeln sich jetzt aus der Oberfläche mit einem einmaligen Code, der Finder kann einen Platzhalter herunterladen oder mit einem Rechtsklick Platz freigeben, die macOS-App wird aus einem Disk-Image installiert, Geräte erreichen einander durch NAT, und Wechselplatten können einen Pool bilden.
  • 2026-10-09 Alpha.6: der Quelltext ist öffentlich, und jede Plattform baut in der Cloud
    Das Repository ist jetzt öffentlich auf GitHub unter der Lizenz PolyForm Shield, die nativen Apps für macOS und iOS bauen auf GitHub Actions, Linux, Windows und Android bauen auf kurzlebigen Cloud-Rechnern, und die Oberfläche wurde um eine Dateiansicht neu gemacht.
  • 2026-10-08 Alpha-0: das erste durchgängige Stück
    Ein Werkzeug für die Kommandozeile, das einen Ordner verschlüsselt, auf Speicher legt, der dir gehört, und ihn zwischen zwei Geräten synchronisiert, mit einem signierten Hauptbuch, das du prüfen kannst.
