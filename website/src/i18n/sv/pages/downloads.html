Nedladdningar

Se skärmbilderna för att se hur alfaversionen ser ut.

Ett paket per plattform med bakgrundstjänsten, gränssnittet och samma kommandorad; på Linux och macOS startar tjänsten vid inloggning (en systemd-användarenhet eller en launch agent), på Windows körs den av appen i systemfältet. På Linux och Windows öppnas gränssnittet i din webbläsare; på macOS har den inbyggda appen ett eget fönster. Alfa: använd den bara med testdata och behåll egna säkerhetskopior.

Installera och verifiera

curl -O https://varsto.net/downloads/SHA256SUMS
curl -O https://varsto.net/downloads/varsto-{{VERSION}}-x86_64-unknown-linux-musl.tar.gz
sha256sum -c SHA256SUMS --ignore-missing
tar xzf varsto-{{VERSION}}-x86_64-unknown-linux-musl.tar.gz
cd varsto-{{VERSION}}-x86_64-unknown-linux-musl
./varsto desktop        # opens the desktop interface in your browser
./varsto --help         # command line

Bygg från källkod

Källkoden finns på github.com/janttsu/varsto; varje release är en tagg där, med samma filer bifogade till sin GitHub-release, och källkodsarkivet nedan motsvarar den. Med en stabil Rust-verktygskedja (1.85 eller nyare): git clone https://github.com/janttsu/varsto.git eller packa upp arkivet, och sedan cargo build --release; den körbara filen är target/release/varsto. cargo test --workspace kör testsviten, inklusive scenarierna med två enheter.

Skrivbordsgränssnitt

På Linux och Windows är standard varsto tray: en ikon i systemfältet med öppna och pausa, och ett installationsval när en nyare version finns; bakgrundstjänsten synkroniserar ändringar inom några sekunder på egen hand. varsto desktop startar en liten webbserver bunden till 127.0.0.1 på en slumpmässig port, skriver ut en engångslänk med en sessionstoken och öppnar den i din standardwebbläsare. Bara program på den här datorn når den; sidan avvisar förfrågningar utan token och förfrågningar vars Host-huvud inte är den lokala adressen. I gränssnittet kan du skapa eller ansluta till ett valv, lägga till lagringsplatser och mappar, dela, ställa in regler och lista dubbletter; synkronisering, verifiering och reparation sköts automatiskt. Appaketet och Varsto Desktop.cmd gör precis detta.

Snabbstart (kommandorad)

export VARSTO_PASSPHRASE='a long passphrase'
varsto --home ~/.varsto-laptop init --name laptop            # prints the vault key once; keep it offline
varsto --home ~/.varsto-laptop storage add-local box /mnt/box
varsto --home ~/.varsto-laptop folder add docs ~/Documents/synced
varsto --home ~/.varsto-laptop sync

# another device that can reach the same storage
varsto --home ~/.varsto-desk join --name desk --vault-key <hex> --storage-path /mnt/box
varsto --home ~/.varsto-desk folder attach docs ~/synced
varsto --home ~/.varsto-desk sync
varsto --home ~/.varsto-desk status --json
varsto --home ~/.varsto-desk fsck --verify

Valvnyckeln är huvudnyckeln i hex. Förlorar du den och alla enheter förlorar du dina data: det finns inget konto och ingen deponering.
