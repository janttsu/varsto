Construye Varsto con nosotros

Varsto es una herramienta de sincronización y copia de seguridad de archivos con cifrado de extremo a extremo, para un almacenamiento que ya es tuyo: buckets de S3, recursos compartidos de NAS, remotos de rclone, discos viejos y tus propios dispositivos. El núcleo está escrito en Rust, el código fuente es público en GitHub y el formato de almacenamiento está especificado por escrito. Es una alfa temprana, el mejor momento para darle forma.

Código fuente en GitHub Incidencias Reglas de contribución (en)

El seguimiento de incidencias es donde se anota el trabajo. Las etiquetas help wanted y good first issue marcan lo que puede tomar quien empieza. Un informe de fallo o una corrección pequeña de la documentación son bienvenidos cuando esa lista está vacía.

En qué trabajarías

Un núcleo en Rust con una especificación escrita

varsto-core contiene el motor: corte en bloques definido por el contenido, cifrado XChaCha20-Poly1305, un libro mayor firmado con firmas híbridas Ed25519 + ML-DSA-65, colocación y políticas de conservación, intercambio de bloques entre pares con cruce de NAT, y backends de almacenamiento para directorios, S3 y rclone. Cada objeto que se escribe en el almacenamiento se describe en la especificación del formato de almacenamiento (en).

Un binario, muchos envoltorios

varsto-cli es la línea de comandos, el servicio en segundo plano, la bandeja y una interfaz web local (HTML, CSS y JavaScript sin más). Unos envoltorios nativos finos lo envuelven: Swift para macOS e iOS, Kotlin para Android, a través de varsto-ffi.

Pruebas que ejecutan redes enteras

Además de las pruebas unitarias y de integración, un laboratorio de máquinas virtuales representa portátiles, ordenadores de sobremesa y servidores detrás de routers domésticos, NAT simétrico e internet público, con un servidor S3 y, cuando hace falta, cortes del almacenamiento, caídas y desfase de reloj. Consulta Testing (en).

Dónde hace falta ayuda

  • Revisión de seguridad de la jerarquía de claves, el modelo de amenazas y la especificación del formato. Los hallazgos siguen la política de seguridad.
  • Plataformas: la bandeja de Windows y la integración con el Explorador, la aplicación de iOS en dispositivos reales y el comportamiento en segundo plano de Android en teléfonos de distintos fabricantes.
  • Redes: el intercambio entre pares y el cruce de NAT en redes distintas de las del mantenedor: NAT de operador, solo IPv6, cortafuegos de empresa.
  • Almacenamiento: pruebas con más proveedores compatibles con S3 y backends de rclone, y sus peculiaridades (lecturas por rango, desfase de reloj, coherencia de los listados).
  • Empaquetado: Flatpak, Homebrew, AUR, winget y otros gestores de paquetes.
  • Traducciones: la interfaz está en inglés, finés, sueco, alemán, español y ruso, y este sitio web también en esos idiomas y en francés; más idiomas y la revisión por hablantes nativos son bienvenidos. Los diccionarios son archivos JSON en crates/varsto-cli/ui/i18n/.
  • Documentación e informes de fallos de instalaciones reales: el seguimiento de incidencias (hay un forum previsto).

Cómo empezar

git clone https://github.com/janttsu/varsto
cd varsto
cargo build --release
cargo test --workspace

Basta una cadena de herramientas de Rust estable (1.85 o posterior) para el núcleo y la línea de comandos. El inicio rápido (en) crea una bóveda en un directorio local en un minuto, así que puedes probar cambios sin ninguna cuenta en la nube. Antes de una pull request tienen que pasar cargo fmt --all --check, cargo clippy --workspace --all-targets y las pruebas, y el comportamiento nuevo necesita pruebas. Abre una incidencia antes de cambios grandes.
