Собирай Varsto вместе с нами

Varsto — инструмент синхронизации файлов и резервного копирования со сквозным шифрованием для хранилища данных, которое у тебя уже есть: бакеты S3, ресурсы NAS, удалённые ресурсы rclone, старые диски и свои устройства. Ядро написано на Rust, исходный код открыт на GitHub, формат хранения записан текстом. Это ранняя альфа, и сейчас проще всего повлиять на неё.

Исходный код на GitHub Задачи Правила участия (en)

В трекере задач записана работа. Метки help wanted и good first issue отмечают пункты, которые может взять новый участник. Сообщение об ошибке или небольшая правка документации уместны и когда список пуст.

Над чем будешь работать

Ядро Rust с записанной спецификацией

varsto-core держит движок: разбиение по содержимому, шифрование XChaCha20-Poly1305, подписанный журнал учёта с гибридными подписями Ed25519 + ML-DSA-65, размещение и правила хранения, обмен блоками между узлами с проходом через NAT и бэкенды хранения для каталогов, S3 и rclone. Каждый объект в хранилище данных описан в спецификации формата хранения (en).

Один бинарный файл, много оболочек

varsto-cli — это командная строка, фоновая служба, трей и локальный веб-интерфейс (обычные HTML, CSS и JavaScript). Его оборачивают тонкие нативные оболочки через varsto-ffi: Swift для macOS и iOS, Kotlin для Android.

Тесты, которые гоняют целые сети

Кроме модульных и интеграционных тестов лаборатория виртуальных машин изображает ноутбуки, настольные компьютеры и серверы за домашними роутерами, симметричным NAT и в публичном интернете. Есть сервер S3, а обрывы хранилища данных, падения и расхождение часов включаются по запросу. См. Тестирование (en).

Где нужна помощь

  • Разбор безопасности иерархии ключей, модели угроз и спецификации формата. Находки идут по политике безопасности.
  • Платформы: трей Windows и интеграция с Explorer, приложение iOS на настоящих устройствах, фоновое поведение Android на телефонах разных производителей.
  • Сети: обмен между узлами и проход через NAT не в сети самого сопровождающего: операторский NAT, только IPv6, корпоративные межсетевые экраны.
  • Хранение: проверки на большем числе S3-совместимых поставщиков и бэкендов rclone и их особенности (чтение диапазонов, расхождение часов, согласованность списков).
  • Упаковка: Flatpak, Homebrew, AUR, winget и другие пакетные менеджеры.
  • Переводы: интерфейс на английском, финском, шведском, немецком, испанском и русском, а этот сайт ещё и на этих языках и на французском. Новые языки и проверка носителями приветствуются. Словари — JSON-файлы в crates/varsto-cli/ui/i18n/.
  • Документация и сообщения об ошибках с реальных установок: трекер задач (forum планируется).

С чего начать

git clone https://github.com/janttsu/varsto
cd varsto
cargo build --release
cargo test --workspace

Для ядра и командной строки хватает стабильного набора инструментов Rust, версия 1.85 или новее. Быстрый старт (en) создаёт хранилище в локальном каталоге за минуту, так что изменения можно пробовать без облачной учётной записи. Перед pull request должны пройти cargo fmt --all --check, cargo clippy --workspace --all-targets и тесты, а новое поведение нуждается в тестах. Перед крупными изменениями открой issue.
