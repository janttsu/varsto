Все сравнения

Varsto и git-annex

git-annex управляет большими файлами с помощью git, не храня их содержимое в git. Это сильный инструмент для технических пользователей, которые архивируют, делают резервные копии и перевозят данные по многим дискам и удалённым ресурсам, и он ближайший родственник Varsto в этом списке.

Где отличается Varsto

  • Та же идея отслеживания расположения, но шифрование имён файлов и содержимого всегда включено, на каждом хранилище данных.
  • Непрерывная фоновая синхронизация, интерфейс для компьютера и телефона, общий доступ другим людям и правила хранения, которые предупреждают до того, как правило нарушится.
  • Резервные копии как снимки только для чтения со сроком хранения в твоих хранилищах данных.
  • Путь импорта из репозиториев git-annex, диск за диском, сделан заново в 0.0.1-alpha.14. git-annex — более зрелый инструмент и свободное ПО; смотри ниже.

Как работает git-annex

Каждый репозиторий может жить на любой машине или диске, а special remotes достают до S3 и совместимых хранилищ, rclone, rsync, обычных или съёмных каталогов, WebDAV и другого. Ветка git записывает, какой репозиторий держит каждый файл («git annex whereis»), а numcopies отказывается удалять содержимое, пока в других местах нет достаточно проверенных копий. Шифрование необязательно для каждого special remote и использует GnuPG; имена файлов в самом репозитории git остаются видны, если не использовать gcrypt. Это в основном инструмент командной строки; есть более простой помощник, на Android он работает через Termux, а приложения для iOS нет.

Что подойдёт

git-annex

Выбирай git-annex, когда тебе привычны git и командная строка, ты хочешь максимум контроля и прозрачности и ценишь зрелый инструмент свободного ПО выше готового приложения.

Varsto

Varsto стремится дать те же гарантии (каждая копия учтена, есть правила, сколько копий должно существовать, съёмные диски приходят и уходят) людям, которые не пользуются git: непрерывную фоновую синхронизацию, интерфейс для компьютера и телефона, шифрование, которое всегда покрывает имена и содержимое, пиринговую передачу и общий доступ другим людям.

Varsto — программа в стадии альфа: не доверяй ей данные, у которых нет другой копии; её криптография не проходила независимый аудит. Остальные продукты здесь зрелые. Факты о них сверены с их собственной документацией в октябре 2026 года; цены и тарифы меняются часто, актуальные цифры смотри на их страницах. Исправления приветствуются как issue на GitHub.
