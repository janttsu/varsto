Снимки экрана

Снято автоматически с версии 0.0.1-alpha.16 (commit 64346c5) 2026-11-04, прогон GitHub Actions 343. Каждая сборка на GitHub Actions снимает эти картинки заново на чистых машинах (Linux, Windows, macOS, эмулятор Android и iOS Simulator), с выдуманным демонстрационным хранилищем: ноутбук с двумя папками и телефон, который держит папку фото в выборочном режиме. Интерфейс компьютера — одна и та же страница на Linux, macOS и Windows: её отдаёт фоновая служба, а рисует твой браузер, поэтому отличается только рамка окна: на Linux и Windows её рисует браузер, на macOS — собственное окно приложения.
