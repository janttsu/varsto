All comparisons

Varsto and git-annex

git-annex manages large files with git without storing their contents in git. It is a powerful tool for technical users who archive, back up and move data across many drives and remotes, and it is the closest relative of Varsto on this list.

Where Varsto differs

  • The same location-tracking idea, but encryption of file names and content is always on, on every storage.
  • Continuous background sync, a desktop and phone interface, sharing with other people, and policies that alert before a rule breaks.
  • Backups as read-only snapshots with a retention period on your storages.
  • An import path from git-annex repositories, disk by disk, is built new in 0.0.1-alpha.14. git-annex is the more mature tool and free software; see below.

How git-annex works

Each repository can live on any machine or disk, and "special remotes" reach S3 and compatible stores, rclone, rsync, plain or removable directories, WebDAV and more. A git branch records which repository holds each file ("git annex whereis"), and numcopies refuses to drop content unless enough verified copies exist elsewhere. Encryption is optional per special remote, using GnuPG; file names in the git repository itself stay visible unless gcrypt is used. It is mainly a command-line tool; there is a simpler assistant, Android works through Termux, and there is no iOS app.

Which one fits

git-annex

Choose git-annex when you are comfortable with git and the command line, want maximum control and transparency, and value a mature free-software tool over a ready-made app.

Varsto

Varsto aims to give the same guarantees (every copy accounted for, rules for how many copies must exist, removable disks that come and go) to people who do not use git: continuous background sync, a desktop and phone interface, encryption that always covers names and contents, peer-to-peer transfer and sharing with other people.

Varsto is alpha software: do not trust it with data you have no other copy of, and its cryptography has not been independently audited. The other products here are mature. Facts about them were checked from their own documentation in October 2026; prices and plans change often, so see their own pages for current figures. Corrections are welcome as GitHub issues.
