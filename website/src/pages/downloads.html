Alpha-0 is one small binary with a command-line interface and a local desktop interface (varsto desktop, or just double-click the app) that opens in your browser and talks only to this computer. No mobile app yet. Use it with test data only and keep your own backups.

Install and verify

curl -O https://varsto.soderlund.in/downloads/SHA256SUMS
curl -O https://varsto.soderlund.in/downloads/varsto-0.0.1-alpha.2-x86_64-unknown-linux-musl.tar.gz
sha256sum -c SHA256SUMS --ignore-missing
tar xzf varsto-0.0.1-alpha.2-x86_64-unknown-linux-musl.tar.gz
cd varsto-0.0.1-alpha.2-x86_64-unknown-linux-musl
./varsto desktop        # opens the desktop interface in your browser
./varsto --help         # command line

Build from source

The source archive matches the tagged release. With a stable Rust toolchain (1.85 or newer): unpack, then cargo build --release; the binary is target/release/varsto. cargo test --workspace runs the test suite, including the two-device scenarios.

Desktop interface

On Linux and Windows the default is varsto tray: a tray icon that runs the background service, syncs changes within seconds, and offers open, sync now, pause and update. varsto desktop starts a small web server bound to 127.0.0.1 on a random port, prints a one-time link with a session token and opens it in your default browser. Only programs on this computer can reach it; the page refuses requests without the token and requests whose Host header is not the local address. From the interface you can create or join a vault, add storages and folders, sync, check the storage (fsck) and list duplicates. The app bundle and Varsto Desktop.cmd do exactly this.

Quick start (command line)

export VARSTO_PASSPHRASE='a long passphrase'
varsto --home ~/.varsto-laptop init --name laptop            # prints the vault key once; keep it offline
varsto --home ~/.varsto-laptop storage add-local box /mnt/box
varsto --home ~/.varsto-laptop folder add docs ~/Documents/synced
varsto --home ~/.varsto-laptop sync

# another device that can reach the same storage
varsto --home ~/.varsto-desk join --name desk --vault-key <hex> --storage-path /mnt/box
varsto --home ~/.varsto-desk folder attach docs ~/synced
varsto --home ~/.varsto-desk sync
varsto --home ~/.varsto-desk status --json
varsto --home ~/.varsto-desk fsck --verify

The vault key is the master key in hex. Losing it and every device means losing the data: there is no account and no escrow.
