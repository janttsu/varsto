Forum

Questions, setups, ideas and bug reports go to GitHub issues and discussions for now. A community forum of its own is planned and will be announced on the blog.

  • Getting started and help: installing, creating a vault, pairing devices, and anything that does not work as expected. Add your platform and the Varsto version.
  • Bug reports: reproducible problems, as issues on the issue tracker.
  • Ideas and feature requests, storage and setups (S3 providers, NAS, disk pools, transferrers, policies), security and cryptography and development: discussions.

Never post passphrases, vault keys, recovery words, storage credentials or logs with personal data. Report security vulnerabilities privately; see the security policy.
