Forum

Questions, setups, ideas and bug reports: the community forum is at forum.varsto.net.

  • Getting started and Help & support: installing, creating a vault, pairing devices, and anything that does not work as expected. Add your platform and the Varsto version.
  • Bug reports: reproducible problems. The issue tracker on GitHub is just as welcome.
  • Ideas & feature requests, Storage & setups (S3 providers, NAS, disk pools, transferrers, policies), Security & cryptography, Development and General.

Never post passphrases, vault keys, recovery words, storage credentials or logs with personal data. Report security vulnerabilities privately; see the security policy.
