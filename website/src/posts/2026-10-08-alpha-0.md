Alpha-0 is the first thing you can run. It is deliberately narrow: one storage backend (a directory), a command-line tool with a small local desktop interface, and the smallest set of mechanisms that make the core idea real.

## What the core idea is

Most encrypted sync products run a server that at least sees who connects when, and usually sells the storage too. Varsto has no server. Your devices write encrypted objects into storage that you own, and they write a signed, encrypted record of what they did next to the data. Another device that reaches the same storage reads that record, verifies the signatures, and knows what exists, where it is and which copies have been checked. Two devices that are never online at the same time still end up with the same files.

## What alpha-0 does

- cuts files into content-defined chunks and encrypts each one with a key derived from the chunk's own keyed hash, so the same content becomes the same object on every device and deduplicates without coordination;
- writes chunks, folder manifests and ledger batches into a local-directory storage with put-if-absent semantics, one writer per path, no locks;
- merges manifests with version vectors; concurrent edits keep both versions as a conflict copy, a deletion never beats a concurrent edit, and deleted files go to a local trash;
- detects a device restored from an old backup and refuses to let it sign further;
- `fsck --verify` re-hashes every object a folder references and reports claims the storage cannot back.

The format is written down in [alpha-0-format.md](../../docs/spec/alpha-0-format.md), including every known limitation.

## What it does not do

No sharing with other people, no peer-to-peer transfer, no S3 or rclone yet, no security keys, no mobile apps, and the post-quantum hybrid of the design is not in the code yet (every object carries an algorithm identifier so it can be added without rewriting data). Nothing has been audited. Please use test data only.

## How to try it

Download the Linux binary, the macOS app or the Windows zip from the [downloads page](../downloads/), verify the checksum, and follow the quick start. Two directories on one machine are enough to see the ledger and the sync work; two machines with a shared USB disk or a network mount show the real thing.
